# Hotel Management System

A web-based Hotel Management System developed as an academic project during my **6th semester of Diploma**.

## About the Project

This project was developed to understand how hotel operations can be managed through a web application. It includes customer registration, login, room booking, and administrative features for managing reservations and hotel information.

## Features

- User registration and login
- Room booking and reservation management
- Admin dashboard
- Room and staff management
- Booking and payment records
- Database integration

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL

## How to Run Locally

1. Install XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Start Apache and MySQL.
4. Import the supplied SQL file into a local test database after reviewing its contents.
5. Configure the database connection in `config.php`.
6. Open `http://localhost/Hotel-Management-System/` in your browser.
